## 📋 Module 1: Sales & Operational Data Analysis

### 🎯 Objective
Analyze customer order data and automatically derive key business metrics using formulas.

### 🔑 Key Solutions Implemented

- **Revenue Attribution**
  - Calculated total revenue per SKU and per Order ID using conditional aggregation

- **Regional Performance Analysis**
  - Isolated unit sales metrics specifically for the *East* region

- **Sales Channel Analysis**
  - Identified revenue contribution across platforms such as **Amazon, Shopify, and Faire**

- **Advanced Aggregations**
  - **Average Order Value (AOV)** calculated using unique Order IDs  
  - Identified the **category with the lowest average unit price**  
  - Extracted **unique product categories** dynamically

All insights were generated using **formulas only**, ensuring scalability and automation.

## 📦 Module 2: Packaging & Logistics Optimization

### 🎯 Objective
Optimize *Pick & Pack* operations by selecting the **smallest feasible shipping box** for each order to reduce logistics costs while maintaining safety.

### 🧠 Optimization Logic

For each case:
- Product dimensions and quantities were evaluated
- Total volume and stacking constraints were considered
- The most efficient box was selected from a predefined inventory

### 📊 Box Selection Summary

| Case | Order Scenario | Selected Box | Optimization Rationale |
|-----:|--------------|--------------|------------------------|
| **Case 1** | Mixed plates and bowls | **BX2 (10×10×10)** | Optimized for compact, stackable circular items |
| **Case 2** | Large trays (22”) + plates | **BX5 (16×16×12)** | Required additional length and width clearance |
| **Case 3** | Bulk tray and bowl orders | **BX5 (16×16×12)** | Optimized for vertical stacking and depth |
| **Case 4** | High-quantity mixed SKUs | **BX5 (16×16×12)** | Safely accommodates multiple product heights |

This approach mirrors **real warehouse decision-making** used in logistics operations.
